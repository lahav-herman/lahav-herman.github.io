# files/

General-purpose downloads, unrelated to any specific project. Flat structure — just drop
files straight in here:

```
files/
└── <whatever>
```

Each file also needs a line added to [`files.html`](../files.html) linking to it
(`files/<filename>`) — this repo has no server-side code, so nothing here is auto-listed.

This is separate from the project write-ups on the homepage: those link straight to their
GitHub repos for source code. This folder is for anything else you want to share a direct
download link to.
