Hex Encoder / Decoder

A command-line tool for custom hexadecimal encoding and decoding.

Takes text in and produces a custom hex-encoded form out, and back again. Built as a practical exercise in file I/O, JSON handling, and structuring a small Python project across multiple modules rather than one script.

Beyond plain encode/decode, it supports an optional secret key that shifts the encoding and a noise parameter that pads the output — enough to make the result non-trivial to reverse without the tool, without pretending to be real cryptography.

LanguagePython 3
DependenciesNone — standard library only (argparse)
InterfaceCommand-line, file or terminal input/output
Sourcegithub.com/lahav-herman/custom-dexdec-encoding
# Encode text typed into the terminal, print the result
python main.py -e -rt -s mysecret -n 4 -ot

# Decode a file, write the result to another file
python main.py -d -rf encoded.txt -s mysecret -of decoded.txt
-e / --encodeRun in encode mode
-d / --decodeRun in decode mode
-rtRead input from the terminal
-rf <path>Read input from a file
-s / --secret <key>Secret key used to shift the encoding
-n / --noise <int>Amount of padding noise added to the output
-otPrint the result to the terminal
-of <path>Write the result to a file
-c <name>Create an empty file at startup

Automatic Vulnerability Scanner

A Python automation pipeline for bug bounty reconnaissance.

Chains together a sequence of recon tools into a single run: subdomain discovery, DNS resolution, web probing, crawling, and vulnerability template scanning — against one target domain, with no manual steps in between.

Given a domain, the pipeline runs, in order:

  1. subfinder — enumerate subdomains
  2. dnsx — resolve which hosts are live
  3. httpx — probe for web servers (ports 80, 443, 8080)
  4. katana — crawl discovered hosts (depth 5)
  5. nuclei — scan for known vulnerabilities (low through critical severity)

Each stage logs its own output and is checked for a non-empty result before the next stage runs, so a silent failure partway through doesn't waste the rest of the scan.

LanguagePython 3.12+
Requiressubfinder, dnsx, httpx, katana, nuclei (ProjectDiscovery toolchain), termcolor
PlatformLinux / macOS (shells out to external CLI tools)
Sourcegithub.com/lahav-herman/automatic-vulnerabillity-scanner
python launcher.py
# prompts for a target domain, asks for confirmation,
# then runs the full pipeline and logs each stage to <domain>_BB/
